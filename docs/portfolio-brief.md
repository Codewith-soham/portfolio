## 3. Design Direction & Aesthetic Foundation

### Visual Reference & Mood
* **Inspiration:** ThemeWagon Grunge portfolio visual direction (expressive typography, dark workspace feel, oversized typography, editorial framing, high-contrast layouts).
* **Persona:** Developer workspace + Technical architecture portfolio + Editorial/Grunge aesthetic.
* **Key Design Guardrails:**
  * **No generic templates:** Avoid boilerplate student portfolio looks.
  * **No excessive SaaS polish:** Avoid neon gradient blobs, heavy glassmorphism, and meaningless skill bars.
  * **Intentionality:** Every element should feel engineered—monospaced technical tags, clean architectural grid lines, high-contrast typography, and subtle micro-interactions.

### Design Tokens
* **Backgrounds:**
  * Base canvas: `#08080a` (Deep Obsidian / Near Black)
  * Elevated surfaces / cards: `#101115`
  * Secondary container: `#1b1e27`
* **Text Hierarchy:**
  * Primary: `#f4f4f6` (Off-white / High contrast)
  * Secondary: `#9ca3af` (Muted Zinc / Slate)
  * Muted / Code meta: `#6b7280`
* **Accent Color:**
  * Restrained Accent: `#eab308` (Industrial Amber / Terminal Glow)
  * Subtle Borders: `rgba(255, 255, 255, 0.08)` / `#22242a`
* **Typography:**
  * Display / Headlines: `Space Grotesk` (Bold, structural, editorial)
  * Body text: `Inter` (Legible, crisp)
  * Technical / Code: `JetBrains Mono` (Monospaced metrics, API payloads, status indicators)
